SUBTASK 1: Investigating GitHub and GitLab 
Core Distinction in Licensing Approaches
The core distinction lies in their development models and licensing:
•	GitHub is a proprietary, closed-source platform owned by Microsoft. Its source code is not publicly available, and it operates as a commercial service. While GitHub offers free tiers for public and private repositories, the underlying platform is not open-source.
•	GitLab is an open-source platform (Community Edition) released under the MIT License. Its source code is publicly available, and anyone can view, modify, and self-host GitLab on their own servers. GitLab also offers a proprietary Enterprise Edition with additional features.
Common Features 
1.	Git Repository Hosting – Both host Git repositories for version control.
2.	Pull/Merge Requests – Both allow code review and collaboration through pull requests (GitHub) or merge requests (GitLab).
3.	CI/CD Pipelines – Both offer integrated continuous integration and continuous deployment tools (GitHub Actions; GitLab CI/CD).
4.	Issue Tracking – Both provide built-in issue tracking and project management boards.
5.	Free Private Repositories – Both offer free private repositories for individual users.
6.	Wiki and Documentation – Both support project wikis and README documentation.
7.	Team Collaboration & Permissions – Both allow organizations, teams, and granular access control.
GitHub Unique Features 
1.	GitHub Actions – A mature, marketplace-driven automation platform with thousands of pre-built actions.
2.	GitHub Copilot – AI-powered code completion integrated directly into the editor.
3.	GitHub Packages – Integrated package registry for npm, Docker, Maven, NuGet, and more.
4.	GitHub Pages – Free static website hosting directly from a repository.
5.	Largest Open-Source Community – The world's largest collection of public repositories and developers.
GitLab Unique Features 
1.	Self-Hosting / On-Premises Deployment – Full control over infrastructure with the open-source Community Edition.
2.	Built-in Container Registry & Kubernetes Integration – Native Docker image registry and Kubernetes cluster management.
3.	GitLab Auto DevOps – Automated CI/CD pipeline generation with minimal configuration.
4.	Integrated DevSecOps – Security scanning (SAST, DAST, dependency scanning) built into the pipeline.
5.	Epics and Roadmaps – Advanced portfolio and project management features for large organizations.
